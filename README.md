# Real-Gas Thermodynamic Properties Using Cubic EOS

## Overview
A Python-based computational project developed
for the Chemical Engineering Thermodynamics course.

The program predicts real-gas thermodynamic
properties using four cubic equations of state:
- Van der Waals (vdW)
- Redlich-Kwong (RK)
- Soave-Redlich-Kwong (SRK)
- Peng-Robinson (PR)

## Calculated Properties
- Pressure-volume-temperature (PVT) behaviour
- Compressibility factor
- Enthalpy and entropy
- Fugacity
- Vapour pressure
- Latent heat

## Technologies Used
- Python
- NumPy
- SciPy
- Matplotlib

## Validation
Results were compared with textbook examples
and CoolProp reference data.
